# Stack Sans website fonts

These unmodified variable fonts are the website's production typography.
Stack Sans Headline is used for page titles/H1s and large closing CTA actions,
retaining uppercase heroes at weight 700. Stack Sans Text is used for H2–H6
headings, labels, buttons, body copy and navigation. Stack Sans Notch is retained
for rollback but is not loaded.
Regular copy uses weight 300; navigation, section headings and supporting labels
use 400. Action-button labels use 500; the closing demo action uses 700.
All three faces support weights 200–700 and use Astro's local font provider.

Source: the Google Fonts repository, retrieved 16 October 2026.
