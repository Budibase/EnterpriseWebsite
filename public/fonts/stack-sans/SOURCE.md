# Stack Sans website fonts

These unmodified variable fonts are the website's production typography.
Stack Sans Notch is reserved for page titles and H1s, including uppercase
heroes at weight 700. Stack Sans Text is used for H2–H6 headings, labels, buttons,
body copy and navigation.
Regular copy uses weight 300; navigation, section headings and supporting labels
use 400. Action-button labels use 500.
Both support weights 200–700 and are served through Astro's local font provider.

Source: the Google Fonts repository, retrieved 16 October 2026.
