# Website font source assets

Inter was downloaded unmodified from the official Google Fonts repository on
19 October 2026. Its directory contains the original variable TTF and SIL Open
Font License.

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter)

These files are reproducible inputs to `scripts/optimize-brand-fonts.py`.
The website loads the optimized Inter WOFF2 derivative in `src/assets/fonts/`.
See `src/assets/fonts/README.md` for coverage, derivative names and regeneration.
