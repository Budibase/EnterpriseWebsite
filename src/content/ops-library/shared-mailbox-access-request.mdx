## Keep mailbox access with its owner

Track shared-mailbox access requests through validation, owner approval, and permission updates. The agent collects the relevant context and keeps the access change connected to its recorded decision.

## How it works

A requester submits a shared mailbox access request through Slack, Teams, or the Shared Mailbox Access Form, creating a tracked request row. The agent confirms the request type, retrieves context from Microsoft Graph and mailbox ownership records, checks the relevant policy source, and asks for any missing details in chat.

Where policy permits, the agent completes access for pre-approved team mailboxes where requester role and owner policy match and records the outcome without waiting for manual handling. The agent escalates sensitive mailboxes, send-as permissions, external users, or missing owner approval to the responsible owner with a decision summary and supporting context.

An approver reviews the escalation in chat or the Mailbox Owner Review Queue, then approves, rejects, or returns it for more information.

## Where people stay in control

People remain responsible for approval exceptions; risky or ambiguous requests.
