## Check software requests against approved policy

Give employees a clear route to request software while IT retains control of what is installed. The agent checks the approved software policy and prepares exceptions for review before the request moves forward.

## How it works

A requester submits a software installation request through Slack, Teams, or the Software Install Request Form, creating a tracked request row. The agent confirms the request type, retrieves context from software catalog and endpoint management, checks the relevant policy source, and asks for any missing details in chat.

Where policy permits, the agent completes approved catalog software for eligible devices and roles and records the outcome without waiting for manual handling. The agent escalates unapproved software, license conflicts, admin rights, or security review requirements to the responsible owner with a decision summary and supporting context.

An approver reviews the escalation in chat or the Software Review Queue, then approves, rejects, or returns it for more information.

## Where people stay in control

People remain responsible for approval exceptions; risky or ambiguous requests.
