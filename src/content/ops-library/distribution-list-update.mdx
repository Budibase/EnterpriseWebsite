## Keep membership changes controlled

Track distribution-list membership changes from request to completion. The agent checks the request against policy, obtains owner approval where required, and records the change and its outcome.

## How it works

A requester submits a distribution list update through Slack, Teams, or the Distribution List Update Form, creating a tracked request row. The agent confirms the request type, retrieves context from Microsoft Graph and directory records, checks the relevant policy source, and asks for any missing details in chat.

Where policy permits, the agent completes membership updates for lists with delegated self-service rules and records the outcome without waiting for manual handling. The agent escalates restricted lists, external members, missing list ownership, or unclear justification to the responsible owner with a decision summary and supporting context.

An approver reviews the escalation in chat or the List Owner Review Queue, then approves, rejects, or returns it for more information.

## Where people stay in control

People remain responsible for approval exceptions; risky or ambiguous requests.
