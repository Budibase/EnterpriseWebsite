## Find answers in approved company knowledge

Employees ask a question instead of searching across disconnected tools. The assistant selects the relevant knowledge domain, retrieves documents from GitHub or Notion, and responds from those sources with a citation rather than relying on model memory.

## How it works

A user submits a natural-language question through chat or email. The agent determines whether the request belongs to IT, HR, operations, or onboarding.

The workflow looks up GitHub documents or Notion page IDs using the selected domain. The agent fetches the most relevant document content and source URL, retrying when needed.

The agent answers strictly from the retrieved content and includes a source citation. If no definitive answer is available, the agent routes the user to the most relevant resource or support team.

## Where people stay in control

People remain responsible for escalation when documentation does not answer the question; maintenance of source documents and system mappings; deployment channel and support workflow design. Answers must be grounded in retrieved documents. If the sources do not provide a definitive answer, the assistant directs the user to the relevant resource rather than guessing.

## Adapt it to your organization

Connect the systems listed alongside this description and configure the workflow for your organization’s data, permissions, and policies. Review the named agents, apps, and automations before using them with your own records.
